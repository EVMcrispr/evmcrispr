# @contract.next

Predict the next contract address deployed by a given account.

**Returns**: `address`

## Syntax

```
@contract.next(creator, offset?)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| creator | `address` | Yes |
| offset | `number` | No |
