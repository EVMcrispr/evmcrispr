# @abi.encodeCall

ABI-encode a function call from its signature and arguments.

**Returns**: `bytes`

## Syntax

```
@abi.encodeCall(signature, ...params)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| signature | `string` | Yes |
| ...params | `any` | No |
