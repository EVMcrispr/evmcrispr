# @filter

Keep elements of an array for which a helper returns truthy.

**Returns**: `array`

## Syntax

```
@filter(arr, fn)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| arr | `array` | Yes |
| fn | `helper` | Yes |
