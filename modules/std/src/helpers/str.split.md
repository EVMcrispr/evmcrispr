# @str.split

Split a string by a delimiter into an array of strings.

**Returns**: `array`

## Syntax

```
@str.split(s, delim)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| s | `string` | Yes |
| delim | `string` | Yes |
