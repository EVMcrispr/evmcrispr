title: "@Ether"
---

Resolve a token symbol to its contract address on the current chain.

**Returns**: `address`

## Syntax

```evml
@Ether(tokenSymbolOrAddress)
```

## Arguments

| Name | Type | Description |
|------|------|-------------|
| `tokenSymbolOrAddress` | `token-symbol` | Token symbol (e.g. `DAI`) or address |
