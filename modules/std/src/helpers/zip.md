# @zip

Combine two arrays element-wise into an array of pairs.

**Returns**: `array`

## Syntax

```
@zip(a, b)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| a | `array` | Yes |
| b | `array` | Yes |
