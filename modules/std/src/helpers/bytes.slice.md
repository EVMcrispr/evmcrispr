# @bytes.slice

Extract a byte range from a bytes value.

**Returns**: `bytes`

## Syntax

```
@bytes.slice(value, start, end?)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| value | `bytes` | Yes |
| start | `number` | Yes |
| end | `number` | No |
