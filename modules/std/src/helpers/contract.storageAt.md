# @contract.storageAt

Read a raw storage slot of a contract.

**Returns**: `bytes32`

## Syntax

```
@contract.storageAt(address, slot)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| address | `address` | Yes |
| slot | `bytes32` | Yes |
