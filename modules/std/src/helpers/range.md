# @range

Generate an array of sequential integers from start (inclusive) to end (exclusive).

**Returns**: `array`

## Syntax

```
@range(start, end)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| start | `number` | Yes |
| end | `number` | Yes |
