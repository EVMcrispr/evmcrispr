# @str.slice

Extract a section of a string.

**Returns**: `string`

## Syntax

```
@str.slice(value, start, end?)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| value | `string` | Yes |
| start | `number` | Yes |
| end | `number` | No |
