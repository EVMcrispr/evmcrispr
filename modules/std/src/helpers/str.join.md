# @str.join

Join array elements into a string with a delimiter.

**Returns**: `string`

## Syntax

```
@str.join(arr, delim)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| arr | `array` | Yes |
| delim | `string` | Yes |
