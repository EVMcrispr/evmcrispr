# @all

Return true if every element satisfies the predicate.

**Returns**: `bool`

## Syntax

```
@all(arr, fn)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| arr | `array` | Yes |
| fn | `helper` | Yes |
