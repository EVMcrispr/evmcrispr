Convert a string to lowercase.

**Returns**: `string`

## Syntax

```evml
@str.lower(s)
```

## Arguments

| Name | Type | Description |
|------|------|-------------|
| `s` | `string` | Source string |

## Examples

```evml
# Lowercase a string
set $s @str.lower("Hello World")
```
