# @str.includes

Check whether a string contains a substring.

**Returns**: `bool`

## Syntax

```
@str.includes(value, item)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| value | `string` | Yes |
| item | `string` | Yes |
