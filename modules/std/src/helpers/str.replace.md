# @str.replace

Replace all occurrences of a substring.

**Returns**: `string`

## Syntax

```
@str.replace(s, old, replacement)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| s | `string` | Yes |
| old | `string` | Yes |
| replacement | `string` | Yes |
