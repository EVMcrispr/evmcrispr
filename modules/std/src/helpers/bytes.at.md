# @bytes.at

Access a single byte by index in a bytes value.

**Returns**: `bytes`

## Syntax

```
@bytes.at(value, index)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| value | `bytes` | Yes |
| index | `number` | Yes |
