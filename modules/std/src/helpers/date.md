# @date

Parse a date string into a Unix timestamp, with an optional offset.

**Returns**: `number`

## Syntax

```
@date(date, offset?)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| date | `string` | Yes |
| offset | `string` | No |
