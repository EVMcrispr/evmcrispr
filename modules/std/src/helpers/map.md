# @map

Transform each element of an array by applying a helper.

**Returns**: `array`

## Syntax

```
@map(arr, fn)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| arr | `array` | Yes |
| fn | `helper` | Yes |
