# @bytes

Convert a value to hex bytes, force UTF-8 encoding, or perform a bitwise operation.

**Returns**: `bytes`

## Syntax

```
@bytes(a, b?, c?)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| a | `any` | Yes |
| b | `string` | No |
| c | `any` | No |
