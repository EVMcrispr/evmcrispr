# @slice

Extract a section of an array.

**Returns**: `array`

## Syntax

```
@slice(value, start, end?)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| value | `array` | Yes |
| start | `number` | Yes |
| end | `number` | No |
