# @reduce

Reduce an array to a single value by applying a helper.

**Returns**: `any`

## Syntax

```
@reduce(arr, fn, initial)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| arr | `array` | Yes |
| fn | `helper` | Yes |
| initial | `any` | Yes |
