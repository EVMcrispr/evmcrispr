# @num.format

Format a number with decimal places (like formatUnits).

**Returns**: `string`

## Syntax

```
@num.format(value, decimals)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| value | `number` | Yes |
| decimals | `number` | Yes |
