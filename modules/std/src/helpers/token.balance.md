# @token.balance

Fetch the token balance of an address in base units.

**Returns**: `number`

## Syntax

```
@token.balance(tokenSymbol, holder)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| tokenSymbol | `token-symbol` | Yes |
| holder | `address` | Yes |
