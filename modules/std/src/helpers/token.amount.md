# @token.amount

Convert a human-readable token amount to its base unit (applying decimals).

**Returns**: `number`

## Syntax

```
@token.amount(tokenSymbolOrAddress, amount)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| tokenSymbolOrAddress | `token-symbol` | Yes |
| amount | `number` | Yes |
