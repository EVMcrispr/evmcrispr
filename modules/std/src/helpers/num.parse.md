# @num.parse

Parse a decimal string with a given number of decimals (like parseUnits).

**Returns**: `number`

## Syntax

```
@num.parse(value, decimals)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| value | `any` | Yes |
| decimals | `number` | Yes |
