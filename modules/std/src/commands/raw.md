# raw

Send a raw transaction with pre-encoded calldata.

## Syntax

```
raw <contractAddress> <data> [value]
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| contractAddress | `address` | Yes |
| data | `bytes` | Yes |
| value | `number` | No |

## Options

| Name | Type |
|------|------|
| --from | `address` |
| --gas | `number` |
| --max-fee-per-gas | `number` |
| --max-priority-fee-per-gas | `number` |
| --nonce | `number` |
