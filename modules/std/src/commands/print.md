---
title: "print"
---

Log values to the console output.

## Syntax

```evml
print [...values]
```

## Arguments

| Name | Type | Description |
|------|------|-------------|
| `[...values]` | `any` | Values to output, space-separated |

## Examples

```evml
# Print a string
print "hello"

# Print multiple values
print "count:" 42

# Print variables
set $name "world"
print "hello" $name
```
