---
title: "load"
---

Load a module to make its commands and helpers available.

## Syntax

```evml
load <moduleName>
```

## Arguments

| Name | Type | Description |
|------|------|-------------|
| `moduleName` | `module` | Module name (e.g. `aragonos`, `sim`) |

## Options

| Name | Type | Description |
|------|------|-------------|
| `--as` | `string` | Module alias for namespacing |

## Examples

```evml
# Load the simulation module
load sim
```
