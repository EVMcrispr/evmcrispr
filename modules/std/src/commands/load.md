# load

Load a module to make its commands and helpers available.

## Syntax

```
load <moduleName>
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| moduleName | `module` | Yes |

## Options

| Name | Type |
|------|------|
| --as | `string` |
