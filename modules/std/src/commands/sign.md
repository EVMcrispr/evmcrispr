# sign

Sign a message or typed data with the connected wallet.

## Syntax

```
sign <variable> [message]
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| variable | `variable` | Yes |
| message | `string` | No |

## Options

| Name | Type |
|------|------|
| --typed | `string` |
