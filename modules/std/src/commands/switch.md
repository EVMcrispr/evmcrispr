---
title: "switch"
---

Switch the active chain by name or ID.

## Syntax

```evml
switch <networkNameOrId>
```

## Arguments

| Name | Type | Description |
|------|------|-------------|
| `networkNameOrId` | `any` | Chain name (e.g. `ethereum`) or numeric chain ID |

## Examples

```evml
# Switch by chain name
switch gnosis

# Switch by chain ID
switch 137
```
