---
title: "@safe:safe.guard"
---

Return the transaction guard address of a Safe (the zero address when no guard is set).

**Returns**: `address`

## Syntax

```evml
@safe:safe.guard(safe?)
```

## Arguments

| Name | Type | Description |
|------|------|-------------|
| `[safe]` | `address` | Safe address (defaults to the context Safe or connected account) |
