Return the current on-chain nonce of a Safe.

**Returns**: `number`

## Syntax

```evml
@safe:nonce(safe?)
```

## Arguments

| Name | Type | Description |
|------|------|-------------|
| `[safe]` | `address` | Safe address (defaults to the context Safe or connected account) |
