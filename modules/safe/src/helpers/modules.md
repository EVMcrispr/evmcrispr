Return the enabled module addresses of a Safe.

**Returns**: `array`

## Syntax

```evml
@safe:modules(safe?)
```

## Arguments

| Name | Type | Description |
|------|------|-------------|
| `[safe]` | `address` | Safe address (defaults to the context Safe or connected account) |
