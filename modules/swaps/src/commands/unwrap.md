---
title: "swaps:unwrap"
---

Unwrap the canonical wrapped-native token back into the native token (WETH to ETH, WXDAI to xDAI...).

## Syntax

```evml
swaps:unwrap <amount>
```

## Arguments

| Name | Type | Description |
|------|------|-------------|
| `amount` | `number` | Wrapped amount to unwrap, in base units (wei) |
