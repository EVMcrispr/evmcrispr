# aragonos:upgrade

Upgrade an installed Aragon app to a new version.

## Syntax

```
aragonos:upgrade <apmRepo> [newAppAddress]
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| apmRepo | `repo` | Yes |
| newAppAddress | `any` | No |
