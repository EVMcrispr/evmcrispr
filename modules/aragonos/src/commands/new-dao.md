# aragonos:new-dao

Create a new Aragon DAO and register it with an ENS name.

## Syntax

```
aragonos:new-dao <variable> <daoName>
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| variable | `variable` | Yes |
| daoName | `string` | Yes |
