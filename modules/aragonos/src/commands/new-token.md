# aragonos:new-token

Create a new MiniMe token with configurable name, symbol, and decimals.

## Syntax

```
aragonos:new-token <variable> <name> <symbol> <controller> [decimals] [transferable]
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| variable | `variable` | Yes |
| name | `string` | Yes |
| symbol | `string` | Yes |
| controller | `address` | Yes |
| decimals | `number` | No |
| transferable | `bool` | No |
