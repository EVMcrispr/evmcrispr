# aragonos:revoke

Revoke a permission from an entity on a DAO app, optionally removing the manager.

## Syntax

```
aragonos:revoke <grantee> <app> <role> [removeManager]
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| grantee | `address` | Yes |
| app | `app` | Yes |
| role | `permission` | Yes |
| removeManager | `bool` | No |
