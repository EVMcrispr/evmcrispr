# @aragonos:app

Resolve an app identifier to its proxy address within the connected DAO.

**Returns**: `address`

## Syntax

```
@aragonos:app(appIdentifier)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| appIdentifier | `string` | Yes |
