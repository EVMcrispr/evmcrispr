# @aragonos:nextApp

Predict the address of the next app to be installed in the DAO.

**Returns**: `address`

## Syntax

```
@aragonos:nextApp(offset?)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| offset | `number` | No |
