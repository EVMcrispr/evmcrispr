# @aragonos:aragonEns

Resolve an Aragon ENS name to its address.

**Returns**: `address`

## Syntax

```
@aragonos:aragonEns(ensName, extra?)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| ensName | `string` | Yes |
| extra | `any` | No |
