# sim:set-code

Set the bytecode at an address in a fork simulation.

## Syntax

```
sim:set-code <address> <bytecode>
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| address | `string` | Yes |
| bytecode | `string` | Yes |
