# sim:set-storage-at

Set a storage slot value at an address in a fork simulation.

## Syntax

```
sim:set-storage-at <address> <slot> <value>
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| address | `address` | Yes |
| slot | `bytes32` | Yes |
| value | `string` | Yes |
