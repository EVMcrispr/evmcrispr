# @http:fetch

Fetch a URL and return the response body as a string.

**Returns**: `string`

## Syntax

```
@http:fetch(url, method?, body?, auth?)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| url | `string` | Yes |
| method | `string` | No |
| body | `string` | No |
| auth | `string` | No |
