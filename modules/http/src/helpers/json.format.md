# @http:json.format

Construct a JSON string from a template and an array of values.

**Returns**: `string`

## Syntax

```
@http:json.format(template, values)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| template | `string` | Yes |
| values | `array` | Yes |
