# @http:json

Parse a JSON string and extract a value by path.

**Returns**: `any`

## Syntax

```
@http:json(data, path)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| data | `string` | Yes |
| path | `json-path` | Yes |
