title: "@semaphore:root"

The current Merkle root of a Semaphore group's member tree.

**Returns**: `number`

## Syntax

```evml
@semaphore:root(group)
```

## Arguments

| Name | Type | Description |
|------|------|-------------|
| `group` | `number` | Group id |
