title: "@gelato:lastTask"

Id of the most recently created active Gelato Automate task of an account — handy right after gelato:automate.

⚗️ **Experimental** — available at [next.evmcrispr.com](https://next.evmcrispr.com).

**Returns**: `bytes32`

## Syntax

```evml
@gelato:lastTask(creator?)
```

## Arguments

| Name | Type | Description |
|------|------|-------------|
| `[creator]` | `address` | Task creator (defaults to the connected account) |
