# ens:renew

Renew ENS domain registrations via bulk renewal.

## Syntax

```
ens:renew <domains> <duration>
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| domains | `any` | Yes |
| duration | `any` | Yes |
