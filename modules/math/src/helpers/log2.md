---
title: "@math:log2"
---

The base-2 logarithm of a whole number, rounded down — the position of its highest set bit, so it also gives a bit length. Undefined at zero.

**Returns**: `number`

## Syntax

```evml
@math:log2(value)
```

## Arguments

| Name | Type | Description |
|------|------|-------------|
| `value` | `number` | Whole number above zero |
