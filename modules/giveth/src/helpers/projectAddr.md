# @giveth:projectAddr

Resolve a Giveth project slug to its contract address.

**Returns**: `address`

## Syntax

```
@giveth:projectAddr(slug)
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| slug | `string` | Yes |
