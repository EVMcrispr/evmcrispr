---
title: "@giveth:projectAddr"
---

Resolve a Giveth project slug to its contract address.

**Returns**: `address`

## Syntax

```evml
@giveth:projectAddr(slug)
```

## Arguments

| Name | Type | Description |
|------|------|-------------|
| `slug` | `string` | Giveth project slug |
