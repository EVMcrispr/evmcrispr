---
title: "@giveth:round"
---

The current GIVpower round number (rounds last 2 weeks; locks unlock when their round is over).

**Returns**: `number`

## Syntax

```evml
@giveth:round
```

## Examples

```evml
# Print the current GIVpower round
print "Current round:" @giveth:round()
```
