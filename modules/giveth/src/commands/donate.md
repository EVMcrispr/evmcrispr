# giveth:donate

Send a donation to a Giveth project.

## Syntax

```
giveth:donate <slug> <amount> <tokenAddr>
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| slug | `string` | Yes |
| amount | `number` | Yes |
| tokenAddr | `address` | Yes |
