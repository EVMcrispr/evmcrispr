# giveth:verify-givbacks

Verify a GIVbacks vote against its IPFS proposal and vote if valid.

## Syntax

```
giveth:verify-givbacks <hash> <voteId>
```

## Arguments

| Name | Type | Required |
|------|------|----------|
| hash | `any` | Yes |
| voteId | `any` | Yes |

## Options

| Name | Type |
|------|------|
| --relayer | `any` |
