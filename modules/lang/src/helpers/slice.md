Extract a section of an array.

**Returns**: `array`

## Syntax

```evml
@lang:slice(value start end?)
```

## Arguments

| Name | Type | Description |
|------|------|-------------|
| `value` | `array` | Input value |
| `start` | `number` | Start index (inclusive) |
| `[end]` | `number` | End index (exclusive) |
