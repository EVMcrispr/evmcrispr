Look up an entry by name in a record (`[a:1 b:2]` or `[name value]` pairs).

**Returns**: `any`

## Syntax

```evml
@lang:lookup(record name)
```

## Arguments

| Name | Type | Description |
|------|------|-------------|
| `record` | `record` | Record (entries array) to look the name up in |
| `name` | `string` | Entry name to look up |
