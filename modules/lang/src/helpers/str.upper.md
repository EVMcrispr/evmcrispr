Convert a string to uppercase.

**Returns**: `string`

## Syntax

```evml
@str.upper(s)
```

## Arguments

| Name | Type | Description |
|------|------|-------------|
| `s` | `string` | Source string |

## Examples

```evml
# Uppercase a string
set $s @str.upper("hello")
```
