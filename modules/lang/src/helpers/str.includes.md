title: "@lang:str.includes"

Check whether a string contains a substring.

**Returns**: `bool`

## Syntax

```evml
@lang:str.includes(value item)
```

## Arguments

| Name | Type | Description |
|------|------|-------------|
| `value` | `string` | Input value |
| `item` | `string` | Substring to search for |
