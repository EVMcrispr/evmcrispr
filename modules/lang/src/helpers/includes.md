title: "@lang:includes"

Check whether an array contains an element.

**Returns**: `bool`

## Syntax

```evml
@lang:includes(value item)
```

## Arguments

| Name | Type | Description |
|------|------|-------------|
| `value` | `array` | Input value |
| `item` | `any` | Element to search for |
