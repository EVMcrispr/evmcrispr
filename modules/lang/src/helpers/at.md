---
title: "@lang:at"
---

Access an element by index in an array.

**Returns**: `any`

## Syntax

```evml
@lang:at(value index)
```

## Arguments

| Name | Type | Description |
|------|------|-------------|
| `value` | `array` | Input value |
| `index` | `number` | Zero-based index (negative counts from end) |
