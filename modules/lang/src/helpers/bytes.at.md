---
title: "@lang:bytes.at"
---

Access a single byte by index in a bytes value.

**Returns**: `bytes`

## Syntax

```evml
@lang:bytes.at(value index)
```

## Arguments

| Name | Type | Description |
|------|------|-------------|
| `value` | `bytes` | Input value |
| `index` | `number` | Zero-based byte index |
