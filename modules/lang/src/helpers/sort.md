Sort an array using a comparator helper.

**Returns**: `array`

## Syntax

```evml
@lang:sort(arr fn)
```

## Arguments

| Name | Type | Description |
|------|------|-------------|
| `arr` | `array` | Source array |
| `fn` | `helper` | Comparator helper returning a number |
