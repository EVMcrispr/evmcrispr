Transpose an array of pairs into two separate arrays.

**Returns**: `array`

## Syntax

```evml
@lang:unzip(pairs)
```

## Arguments

| Name | Type | Description |
|------|------|-------------|
| `pairs` | `array` | Array of [a, b] pairs |
