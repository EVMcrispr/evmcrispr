title: "@lang:str.slice"

Extract a section of a string.

**Returns**: `string`

## Syntax

```evml
@lang:str.slice(value start end?)
```

## Arguments

| Name | Type | Description |
|------|------|-------------|
| `value` | `string` | Input value |
| `start` | `number` | Start index (inclusive) |
| `[end]` | `number` | End index (exclusive) |
