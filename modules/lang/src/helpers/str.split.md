Split a string by a delimiter into an array of strings.

**Returns**: `array`

## Syntax

```evml
@lang:str.split(s delim)
```

## Arguments

| Name | Type | Description |
|------|------|-------------|
| `s` | `string` | Source string |
| `delim` | `string` | Delimiter string |
