Concatenate strings together.

**Returns**: `string`

## Syntax

```evml
@lang:str.concat(first ...rest)
```

## Arguments

| Name | Type | Description |
|------|------|-------------|
| `first` | `string` | First string segment |
| `[...rest]` | `string` | Strings to append |
