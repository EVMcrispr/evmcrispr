Format a number with decimal places (like formatUnits).

**Returns**: `string`

## Syntax

```evml
@lang:num.format(value decimals)
```

## Arguments

| Name | Type | Description |
|------|------|-------------|
| `value` | `number` | Input value |
| `decimals` | `number` | Number of decimal places |
