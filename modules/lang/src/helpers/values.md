title: "@lang:values"
---

Return the entry values of a record (`[a:1 b:2]` or `[name value]` pairs) as an array.

**Returns**: `array`

## Syntax

```evml
@lang:values(record)
```

## Arguments

| Name | Type | Description |
|------|------|-------------|
| `record` | `record` | Record (entries array) to read the values from |
